## 배포 메모 (동시 작업 주의)

이 커밋의 `index.html`은 **당시 라이브 파일(HEAD `770cb18`)에 CSS 블록만 더해** 만들었다.
같은 시각 `handoffs/🗂️-현물출자-플랜을-승계-탭-1번으로-이동` 작업이 `_index.src.html`·`build.py`를
고치고 있었기 때문에, 그 작업의 미완성 빌드를 실수로 배포하지 않으려고 그렇게 했다.
CSS 블록은 `_index.src.html`에 들어 있으므로 **그 작업이 나중에 빌드·배포하면 이 히어로 2배 파일
연결도 자동으로 함께 나간다**(따로 손댈 것 없음). `assets/ceo-hero-2x.webp`는 deploy 폴더에 이미 있음.
`build.py`는 자산을 복사하지 않으므로, 새 환경에서 처음 배포할 때는 이 파일을
`bellarich-deploy/assets/`에 한 번 복사해야 한다.
